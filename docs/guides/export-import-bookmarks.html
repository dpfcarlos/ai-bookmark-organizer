How to export and import bookmarks between browsers

Every major browser can export bookmarks to a standard HTML file and import them from one. This is the safest way to back up your bookmarks, move them to another browser or computer, or clean them with a tool.

Open the free web tool

Steps

  1. Chrome, Edge, Brave, Opera, Vivaldi: exportPress Ctrl+Shift+O (Mac: Cmd+Option+B) to open the bookmarks manager, click the three-dot menu and choose Export bookmarks. Save the .html file.
  2. Chrome, Edge, Brave, Opera, Vivaldi: importIn the same menu choose Import bookmarks and select the file. Chrome puts the result in a folder called Imported; drag its contents to the bookmarks bar if you want them there.
  3. FirefoxPress Ctrl+Shift+O, open Import and Backup, then choose Export Bookmarks to HTML, or Import Bookmarks from HTML to bring a file in.
  4. SafariUse File, Export, Bookmarks to save the file, and File, Import From, Bookmarks HTML File to load one.

Frequently asked questions

Will folders and the bookmarks bar be kept?

Yes. The HTML format keeps folders and marks the bookmarks bar folder. Some browsers place imported items in a new folder that you can drag to where you want.

Does exporting delete anything?

No. Exporting only writes a copy. Nothing is removed from the browser.

What if I have sync turned on?

Deleting bookmarks in the browser also deletes them on your other synced devices. Keep the exported file as your backup before you delete anything.

How can I clean the file before importing?

Use the free AI Bookmark Organizer web tool: it removes duplicates and empty folders, sorts, groups by site and lets you rename and move items, then downloads a clean file.
