How to organize your bookmarks with AI

If you have hundreds of bookmarks, sorting them by hand is tedious. An AI assistant can read your list, propose a folder structure and apply it, as long as it works with backups and asks for your confirmation. There are two ways to do it.

Open the free web tool

Steps

  1. Option A: let a desktop AI app do it through MCPInstall the AI Bookmark Organizer MCP server in an app that supports local MCP servers, for example Claude Desktop, Claude Code, Cursor, VS Code with Copilot, Windsurf, Gemini CLI or Codex CLI. The command is: npx -y github:dpfcarlos/ai-bookmark-organizer (Node.js 18 or newer is required). Then ask: "Organize my Chrome bookmarks into folders by topic".
  2. Let it preview, then confirmThe server changes nothing until you confirm: every change tool runs as a dry run first, makes an automatic backup, and refuses to write while the browser is open. You can restore any backup with one request.
  3. Option B: any AI chat plus the web toolExport your bookmarks to HTML, ask any AI chat to propose categories from your list of titles, then apply the plan by hand in the web tool (move, rename, group by site) and import the clean file.
  4. Keep the structure simpleUse 5 to 12 top-level folders named by purpose (Work, Study, Finance, Shopping, News, Tools), keep the bookmarks bar for the 5 to 10 things you open every day, and archive old items instead of deleting them.

Frequently asked questions

Which AI assistants can organize bookmarks with this project?

Any assistant or app that can run local MCP servers over stdio. The web tool works with any AI chat because it only needs an exported HTML file. Chat websites that accept only remote MCP servers cannot run the local server.

Can the AI delete my bookmarks by mistake?

It can only delete after a preview and your confirmation, and a backup is saved before each change. The backup folder is ~/.bookmark-organizer/backups and the restore_backup tool undoes any change.

Does my data go to an AI company?

The server runs on your computer. What the assistant reads is what you let it read in the conversation, such as titles and addresses. If that is a concern, use the web tool, which sends nothing anywhere.

Which browsers are supported?

Chrome, Edge, Brave, Vivaldi, Opera and Chromium are edited directly. Firefox and Safari work through the HTML export.
