Como remover favoritos duplicados no Chrome, Edge, Firefox e Safari

A maioria dos navegadores não tem um botão para remover favoritos duplicados. O jeito mais rápido e seguro é exportar os favoritos para um arquivo, limpar o arquivo e importar de volta. Leva cerca de cinco minutos e funciona no Chrome, Edge, Brave, Opera, Vivaldi, Firefox e Safari.

Abrir a ferramenta web gratuita

Passo a passo

  1. Exporte seus favoritosNo Chrome, Edge, Brave, Opera ou Vivaldi aperte Ctrl+Shift+O, abra o menu de três pontos e escolha Exportar favoritos. No Firefox aperte Ctrl+Shift+O, depois Importar e backup e Exportar favoritos para HTML. No Safari use Arquivo, Exportar, Favoritos. Guarde esse arquivo: ele é o seu backup.
  2. Abra a ferramenta web gratuitaAcesse a página do AI Bookmark Organizer e solte o arquivo nela. Os duplicados aparecem em vermelho. Nada é enviado para a internet: tudo roda dentro da aba do seu navegador.
  3. Clique em Remover duplicadosA ferramenta considera a mesma página quando os endereços diferem apenas por http ou https, pelo www no início, por uma barra no final, por um #trecho ou por parâmetros de rastreamento como utm_source. Dá para desfazer com um clique.
  4. Baixe o arquivo limpo e importeClique em Baixar arquivo limpo. No navegador, apague os favoritos antigos (abra o gerenciador de favoritos, aperte Ctrl+A e depois Delete) e importe o arquivo novo em Importar favoritos.

Perguntas frequentes

O Chrome tem um recurso próprio para remover favoritos duplicados?

O Chrome não oferece um botão para remover duplicados. O gerenciador de favoritos permite reordenar por título, o que deixa os duplicados lado a lado para você apagar manualmente. Em coleções grandes, exportar e usar uma ferramenta é mais rápido.

Como a ferramenta decide que dois favoritos são duplicados?

Ela compara o endereço ignorando http ou https, o prefixo www, a barra final, o #trecho e parâmetros de rastreamento (utm_*, fbclid, gclid). Links que diferem em qualquer outro parâmetro são mantidos.

É seguro para os meus favoritos?

O arquivo nunca sai do seu computador, e a exportação original continua intacta como backup. Você também pode desfazer cada passo antes de baixar.

Uma IA pode fazer isso por mim?

Pode. O projeto inclui um servidor MCP que permite a assistentes de IA compatíveis encontrar e remover duplicados direto no Chrome, Edge, Brave, Vivaldi e Opera, com prévia e backup automático antes de qualquer alteração.
