Como exportar e importar favoritos entre navegadores

Todo navegador importante exporta favoritos para um arquivo HTML padrão e importa a partir dele. É a forma mais segura de fazer backup, levar os favoritos para outro navegador ou computador, ou limpá-los com uma ferramenta.

Abrir a ferramenta web gratuita

Passo a passo

  1. Chrome, Edge, Brave, Opera, Vivaldi: exportarAperte Ctrl+Shift+O (Mac: Cmd+Option+B) para abrir o gerenciador de favoritos, clique no menu de três pontos e escolha Exportar favoritos. Salve o arquivo .html.
  2. Chrome, Edge, Brave, Opera, Vivaldi: importarNo mesmo menu escolha Importar favoritos e selecione o arquivo. O Chrome coloca o resultado numa pasta chamada Importados; arraste o conteúdo para a barra de favoritos se quiser.
  3. FirefoxAperte Ctrl+Shift+O, abra Importar e backup e escolha Exportar favoritos para HTML, ou Importar favoritos de HTML para trazer um arquivo.
  4. SafariUse Arquivo, Exportar, Favoritos para salvar o arquivo, e Arquivo, Importar de, Arquivo HTML de favoritos para carregar um.

Perguntas frequentes

As pastas e a barra de favoritos são mantidas?

Sim. O formato HTML guarda as pastas e marca a pasta da barra de favoritos. Alguns navegadores colocam os itens importados numa pasta nova que você pode arrastar para onde quiser.

Exportar apaga alguma coisa?

Não. Exportar só grava uma cópia. Nada é removido do navegador.

E se a sincronização estiver ligada?

Apagar favoritos no navegador também os apaga nos outros aparelhos sincronizados. Guarde o arquivo exportado como backup antes de apagar qualquer coisa.

Como limpar o arquivo antes de importar?

Use a ferramenta web gratuita AI Bookmark Organizer: ela remove duplicados e pastas vazias, ordena, agrupa por site e permite renomear e mover itens, depois baixa um arquivo limpo.
