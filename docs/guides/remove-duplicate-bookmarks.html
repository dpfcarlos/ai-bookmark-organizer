How to remove duplicate bookmarks in Chrome, Edge, Firefox and Safari

Most browsers have no one-click tool to remove duplicate bookmarks. The quickest safe way is to export your bookmarks to a file, clean the file, and import it back. It takes about five minutes and works in Chrome, Edge, Brave, Opera, Vivaldi, Firefox and Safari.

Open the free web tool

Steps

  1. Export your bookmarksIn Chrome, Edge, Brave, Opera or Vivaldi press Ctrl+Shift+O, open the three-dot menu and choose Export bookmarks. In Firefox press Ctrl+Shift+O, then Import and Backup, then Export Bookmarks to HTML. In Safari use File, Export, Bookmarks. Keep this file: it is your backup.
  2. Open the free web toolGo to the AI Bookmark Organizer page and drop the file on it. Duplicates are highlighted in red. Nothing is uploaded: everything runs inside your browser tab.
  3. Click Remove duplicatesThe tool treats two links as the same page when they differ only by http versus https, a leading www, a trailing slash, a #fragment or tracking parameters such as utm_source. You can undo with one click.
  4. Download the clean file and import itClick Download clean file. In your browser, delete the old bookmarks (open the bookmarks manager, press Ctrl+A, then Delete) and import the new file with Import bookmarks.

Frequently asked questions

Does Chrome have a built-in way to remove duplicate bookmarks?

Chrome does not offer a one-click duplicate remover. The bookmark manager can reorder items by title, which places duplicates next to each other so you can delete them by hand. For large collections, exporting and using a tool is faster.

How does the tool decide that two bookmarks are duplicates?

It compares the address after ignoring http versus https, the www prefix, a trailing slash, the #fragment and tracking parameters (utm_*, fbclid, gclid). Links that differ in any other parameter are kept.

Is it safe for my bookmarks?

Your file never leaves your computer, and the original export stays untouched as a backup. You can also undo each step before downloading.

Can an AI assistant do this for me?

Yes. The project includes an MCP server that lets compatible AI assistants find and remove duplicates directly in Chrome, Edge, Brave, Vivaldi and Opera, with a preview and an automatic backup before any change.
